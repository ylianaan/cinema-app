# ИС «Кинотеатр»

Информационная система кинотеатра — учебный проект по практике УП.02.01  
(ПМ.02 «Осуществление интеграции программных модулей»)

## Модули

1. **Репертуар и сеансы** — добавление фильмов и расписания
2. **Продажа билетов** — выбор сеанса, визуальный выбор места, контроль занятости
3. **Касса и квитанции** — оформление продажи и список квитанций
4. **Отчётность** — продажи по фильмам и сеансам, общая выручка

## Как запустить

Просто откройте файл `index.html` в браузере (Chrome, Safari, Firefox).

Данные сохраняются в localStorage браузера.

## Структура проекта

```
cinema-app/
├── index.html          # Главная страница
├── css/
│   └── style.css       # Стили
├── js/
│   ├── data.js         # Слой данных (Cinema.Core)

```

## Технологии

- HTML5 + CSS3 + JavaScript (ванильный)
- localStorage для хранения данных
- Модульная структура кода
